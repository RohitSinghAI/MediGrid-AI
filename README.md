# MediGrid AI 🏥🤖

### AI-Powered Handwritten Prescription Analyzer

MediGrid AI is an AI-powered healthcare assistance application designed to analyze handwritten medical prescriptions and convert them into structured digital medical insights.

The system helps users understand prescription information by extracting medicines, dosages, frequency, and important warnings from handwritten prescription images.

> ⚠️ **Disclaimer:** MediGrid AI provides informational support only. It does not replace professional medical advice, diagnosis, or treatment.

---

## 🚀 Features

- 📷 Upload handwritten prescription images
- 🔍 Extract prescription information using AI/OCR
- 💊 Identify medicines from handwritten prescriptions
- 📋 Extract medication dosage and frequency
- ⚠️ Detect and display critical warnings
- 🤖 AI-powered medical support assistant
- 📍 Location-based services
- 🗺️ Nearby pharmacy/location assistance
- 📜 Prescription history
- 📊 Structured prescription analysis
- 💾 Store prescription-related data
- 📄 User guide and application documentation
